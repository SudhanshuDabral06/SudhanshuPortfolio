# Premium Modern Developer Portfolio (Recruiter & Internship Focused)

A clean, responsive, and high-impact portfolio website tailored specifically for software engineering internship candidates and early-career full-stack developers.

## 🚀 Live Tech Stack
- **HTML5**: Semantic tags, accessible structure, SEO & OpenGraph meta tags.
- **Tailwind CSS**: Utility-first styling with a custom refined light theme palette (`slate-50`, `white`, subtle borders, crisp contrast).
- **Vanilla JavaScript**: Zero build tools required. Fast, modular scripts for category filtering, clipboard copy, active scrollspy, and interactive modal.
- **Lucide Icons**: Crisp SVG icons for dev tools, metrics, and actions.
- **Google Fonts**: Plus Jakarta Sans & JetBrains Mono for typography.

---

## 🎯 Recruiter-First Design Highlights

1. **Internship Readiness Badge**:
   - Prominently showcases "Actively Seeking 2026/2027 Software Engineering Internship" with an animated status indicator.
2. **Key Metric Quick Cards**:
   - Instant scannability for hiring managers (GPA, Number of Full Stack Projects, LeetCode / DSA count, code quality).
3. **Categorized Tech Stack**:
   - Divided into Frontend, Backend & APIs, Databases, and DevOps/Tools, plus Computer Science fundamentals (DSA & System Design).
4. **Quantified Project Impact**:
   - Bullet points highlight performance gains (e.g., *"Optimized PostgreSQL queries, cutting latency by 45%"*, *"atomic inventory transactions"*).
5. **Interactive Project Filter**:
   - Recruiters can filter projects by **All**, **Full Stack**, **Frontend**, and **Backend/API**.
6. **Frictionless Contact**:
   - One-click **Copy Email** button with instant toast notification, alongside LinkedIn, GitHub, and a message form.
7. **Interactive Resume Preview & Download**:
   - Pop-up modal with summary and download button.

## ⚡ How to Open and Run

Since this project has **zero external build steps or dependencies**:
1. Simply double click `index.html` to open it directly in any web browser (Chrome, Edge, Firefox, Safari).
2. Alternatively, if using VS Code, right click `index.html` and select **"Open with Live Server"**.
